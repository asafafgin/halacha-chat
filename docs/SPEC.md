# אפיון — הלכה בצ׳אט

> מסמך האפיון כפי שנכתב בפרויקט ב־Lovable, לפני העברת הפיתוח לכאן.

## עיקרון מנחה

המערכת אינה פוסקת הלכה. הבינה המלאכותית משמשת רק לפענוח השאלה, איתור המקור וסידור התוצאות. כל תשובה חייבת להיות מבוססת על מקור שנמצא בפועל — אין המצאת מקורות, ציטוטים או מראי מקום.

## עמודים

- `/` — מפנה אוטומטית לעמוד החיפוש
- `/halacha` — החיפוש: שאלה, סינון ותוצאות
- `/sources` — מדיניות המקורות והמאגרים המחוברים/המתוכננים
- `/sites` — ניהול רשימת האתרים המאושרים
- `/poskim` — פוסקים וספרים לפי עדה

ניווט ראשי: חיפוש · מקורות מידע · אתרים מאושרים · פוסקים. ממשק עברי RTL.

## קלט

- טקסט בעברית טבעית (עד 300 תווים, Enter לחיפוש)
- דיבור — הכתבה קולית בעברית
- תמונה — הבינה מייצרת תיאור עובדתי בלבד (לא שאלה, לא קביעת כשרות/פסלות), והוא משמש הקשר לשאלה שכתבת

## שלבי החיפוש

**שלב א׳ — הבנת השאלה:** מה אתם שואלים בפועל, הנושא, וניסוח החיפוש. הבינה לא מנסחת שאלה חדשה ולא מציעה שאלות.

**שלב ב׳ — סוגיה דומה:** בדיקת הסוגיה הדומה בספרי ההלכה, ואז חיפוש במאגרים. החיפוש משולב עם מילון נרדפות (אתרוג/ארבעת המינים, תפילין, ציצית, שבת, כשרות, ברכות, תפילה, נידה, אבלות, פסח, סוכה, חנוכה, ריבית).

## ספרייה מוגדרת

התשובות נלקחות **רק** מספרייה מוגדרת: ספרים, קישורים ומאגרים שנרשמו מראש (`src/data/library.ts`). ספריא, ויקיטקסט וקישורים הם רק ערוצים להבאת הטקסט של ספר שברשימה. מה שלא ברשימה לא נכנס לתוצאות.

## סינון

לפי עדה (כללי, ספרדי, אשכנזי, תימני, חסידי), לפי פוסק/ספר, ולפי רשימת האתרים המאושרים.

## תוצאות

- רשימת מקורות: שם המקור, מחבר, עדה, מאגר, לשון המקור, מראה מקום וקישור למקור
- השוואת פוסקים: טבלת ספר/פוסק · עדה · לשון המקור · מראה מקום — בלי הכרעה
- אם לא נמצא מקור, או שכולם סוננו מחוץ לרשימה — הודעה מפורשת, בלי השלמה

## אתרים מאושרים

הוספה, סימון/ביטול, מחיקה ושחזור ברירת מחדל; הרשימה נשמרת בדפדפן והסינון מתבצע בשרת.

- **פעילים:** ספריא (2 כתובות), ויקיטקסט, HebrewBooks, אוצר החכמה, מכון התורה והארץ, פניני הלכה, מכון ממרא, דעת, ישיבה, דין, הלכה יומית, אסיף, תורת אמת, שולחן ערוך הרב.
- **כבויים לבחירה:** כיפה, מורשת, הידברות, חב״ד.

## מאגרים

- **פעילים:** ספריא, ויקיטקסט.
- **בהרשאה/מתוכננים:** HebrewBooks, אוצר החכמה, פרויקט השו״ת, מכון התורה והארץ, אתרים רשמיים, מאגר פרטי בהרשאת בעל זכויות.

אין עקיפת הגנות.

## כלל קריטי למקור

כל תשובה בשם פוסק חייבת להציג: שם הרב → שם הספר → חלק/סימן/סעיף/עמוד → לשון המקור → קישור. אסור „הרב פלוני פסק ש…" על סמך הסקת AI. אם נמצאה רק סוגיה דומה — זה נאמר במפורש.

פוסקי תימן: רצאבי, קורח, צובירי (ונוספים שיאושרו); הרב קאפח אינו נכלל.

## מדיניות תמונות

אין חיפוש תמונות אקראי באינטרנט — רק Whitelist וספרים חזותיים שיש הרשאה. לצילום מום באתרוג מוצגים תמונה דומה ממקור תורני + שם הספר/האתר + ההסבר המקורי, בלי לקבוע כשרות.

## טכנולוגיה

- TanStack Start (React 19), TypeScript, Tailwind v4, עברית RTL
- חיפוש וניתוח דרך server functions
- בינה דרך Claude API (משתנה `ANTHROPIC_API_KEY`) להבנת שאלה ותיאור תמונה בלבד. בלי מפתח המערכת עובדת עם חילוץ מילים פשוט.
- הכתובת הראשית מוגדרת במקום אחד (`src/config.ts`)

> הגרסה ב־Lovable השתמשה ב־Lovable AI Gateway. בבנייה מחדש כאן הוחלף לספק עם מפתח משלנו, באותו תפקיד מוגבל.

## עדיין לא נבנה

חשבונות משתמש, שמירת חיפושים, ייצוא, פאנל ניהול, OCR, וזיהוי תמונות מול מקורות חזותיים מורשים.
